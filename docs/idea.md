# TwoOfUs

A private communication platform designed for exactly two people.

Core Principles:

- One account can connect to only one partner.
- One partner can connect to only one account.
- Connection happens through:
  - QR Code
  - Connection PIN
- Once connected:
  - QR becomes invalid
  - PIN becomes invalid
- No second partner can ever connect.
- End-to-end encrypted messaging.
- End-to-end encrypted voice calls.
- End-to-end encrypted video calls.
- Shared memory space for photos and moments.

Connection Flow:

User A
↓
Generate PIN / QR
↓
User B enters PIN or scans QR
↓
Connection established
↓
PIN destroyed
QR destroyed
↓
Permanent pair created

Features:

- Private Chat
- Voice Calls
- Video Calls
- Shared Photos
- Shared Memories
- Relationship Timeline
